# Dietary Intake & RDA Compliance Analysis Source Code

A Python code repository for calculating dietary intake, looking up Recommended Dietary Allowances (RDA), and evaluating adequacy levels for the thesis project: **"Assessment of Dietary Intake and Eating Behaviors in Children..."**

* Libraries: `pandas`, `numpy`
